# IT-учёт

Внутренний сайт сисадмина: учёт техники, склад расходников, журнал ремонтов.
Backend — Flask, база данных — SQLite (файл `inventory.db`, создаётся автоматически при первом запуске).
Страницы рендерятся на сервере через Jinja-шаблоны, все действия (добавить/изменить/удалить) — обычные HTML-формы, без JavaScript.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Сайт откроется на http://127.0.0.1:5050

## Структура БД

Всё в одном файле `schema.sql` — 5 связанных таблиц (`rooms`, `employees`, `equipment`, `warehouse`, `repairs`) и демо-данные (`INSERT`), чтобы сайт не был пустым при первом запуске.
Если нужно начать с чистой базы — удалите `inventory.db`, она будет пересоздана при следующем запуске.
